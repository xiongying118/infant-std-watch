这一页是法律法规与体系文件，按效力层级和适用环节分类。 实验室的检测方法来自标准，但为什么必须做、按什么程序做、出问题谁担责——这些是法律和规章定的。 例：食品安全法是所有判定的上位法，检出不合格即违法； CMA 资质认定管理办法决定你出的报告有没有法律效力； 广告法管的是"检测数据能不能拿去做宣传"—— 婴幼儿配方乳粉广告不得用科研单位或专家作推荐证明。

为什么不自动抓取：国家法律法规数据库（flk.npc.gov.cn）的检索接口经过打包混淆， 实测 6 组参数组合全部返回 500；且法规的"现行/已修订/已废止"本身需要人工核对修订链。 所以这里用静态清单 + 人工维护，每条给官方查询入口。 不存条文全文——只列名称、文号、施行日期与说明。

这一页是实验室认可（CNAS）的依据文件，和上面的「检测方法标准」不是一回事。 标准清单与通则引用回答的是「测什么、怎么测」； 这一页回答的是「凭什么出报告、实验室该达到什么能力」。

CNAS 文件不是国家标准——标准委检索库（openstd / 全国标准信息公共服务平台） 根本不收录，在国标库里搜「CNAS-CL01」是零结果。 所以它必须单独一个源（SRC-11，直接抓 cnas.org.cn）， 混在通则引用里会让检测员误以为它是产品标准强制引用的检测方法。

最常被引用的一份是 CNAS-CL01《检测和校准实验室能力认可准则》， 它是 ISO/IEC 17025 的中文实施版本 —— 评审时对**实验室整体能力**的要求， 不针对某一个检测项目。食品实验室重点看 CL01-A002（化学检测领域）、CL01-A001（微生物检测领域）、 GL006（化学分析不确定度）、EL-06（食品检测领域能力范围表述）。

为什么不存全文——只列编号、名称、发布日期与官方链接。 官方列表没有「实施日期」字段，这里如实标注，不编造。

JSA = 工作安全分析（Job Safety Analysis）。做事前把「哪一步可能出什么事、怎么防」写下来。 它和标准变更提醒是两条并行的线：标准提醒管「按哪一版做」， JSA 管「按这版做的时候别伤到自己」。

风险值 R = 可能性 L × 严重度 S，范围 1~25，分四档： 低 1~4 / 一般 5~9 / 中等 10~14 / 高 15~25。 涉及伤亡 / 中毒 / 职业禁忌的条目，无论 R 多少， 严重度 S 不得低于 3，默认中等以上风险。

这一页是可以直接用的工作台： 表格里的每一步、每个 L/S 评级、每条控制措施都能直接改， 改完 R 值、风险等级、顶部统计、风险矩阵会立即跟着变； 填了建议措施并标记「已落实」，残余风险自动算出来。 导出 CSV / Word / 打印视图，拿去签字归档。

覆盖实验室完整作业链：取样 → 复原 → 常规理化 → 营养素 → 污染物与抗生素 → 微生物常规 → 过敏原与标签 → 计量校准 → 报告数据 → 洗消卫生 → 人员准入，每个分区都有主管 / 备份 / 复核人。 「作业前确认卡」是开工前逐条打勾签字的表 —— JSA 写完不是结束。

⚠ 签字与日期必须手签 —— 这是要留档的正式记录； 本工具帮你把表填完整、把风险算对，不代你签字。

这一页解释「这个检测方法为什么这么做」——每一步用了什么试剂、起什么作用。 检测员真正卡住的地方通常不是「用哪个标准」，而是 「为什么要加这个试剂」「这一步为什么必须做」。
