## ★★ 真正的根因：cfsa 必须用 POST，GET 一律回首页 ★★（22:28 修完）

上面那一版**修法是错的**。用户 22:22 反馈「链接到食品安全国家标准数据检索平台**都是错误的**」。

### 我错在哪
第一版把 guid 拼在 `href` 上（`?type=2&guid=xxx`）。实测这个 URL 的 GET 响应是
**597 字符空壳**，而空壳里的表单是：

```
window.onload=document.getElementById("form1").submit()
<form method=post action="/db"><input name="task" value="index">
```

→ action 是 `/db`、task 是 `index`，**URL 上的 guid 被整个丢掉**，
浏览器 JS 执行后自动POST 出 `task=index`，**回到首页**。
所以「把 guid 拼 href 上」在浏览器里根本走不通，只会把你送到首页。
这就是用户看到的「全是错的」。

**「URL 返回 200」「页面含该标准号」都证明不了浏览器里能打开。**

### 正确做法：POST 表单跳转
```js
POST https://sppt.cfsa.net.cn:8086/db?type=2&guid=<ID>   body: task=goto
```
实测**不需要 cookie**（无 cookie 的跨站 POST → 9612 字符，内容齐全）。
所以用 `postJump(url)`：动态建 form（method=POST、target=_blank），
塞一个`name=task value=goto` 的隐藏域，提交。

### 静态测试的坑（test_links.js / test_cnas_render.js）
1. **切点必须晚于被测函数**：`offLink`/`postJump` 定义在 `const REFGROUPS =` **之后**，
   切在 REFGROUPS 会一起切掉 → 报 `offLink is not defined`（像页面缺函数，其实是切早了）。
   正确切点：`function renderLaw(`。
2. 页面自己声明了 `const $ / $$`，再当函数参数传同名变量 →
   `Identifier '$' has already been declared`。只传 window/document。
3. mock DOM 必须齐：`createElement`（postJump 建 form/input）、

4. 提取内联 script 不能用「最后一个结束标签往前找开始标签」→页里有
   `<script src="data.js"></script>` 自闭合对，会把整页 DOCTYPE 圈进来。
