## 计量设备台账一键导入导出（用户明确要求）
- 导出：CSV / Word / 空白模板（只有表头供填写）
- 导入：CSV 或 JSON → **预览确认**（显示解析行数、列匹配数、未匹配列）→ 选覆盖/追加
- CSV 解析器处理：BOM、引号包裹、内嵌逗号、内嵌换行、双引号转义
- 列映射：优先按中文标签精确匹配，匹配不上按列顺序兜底
- 全部 14 个台账共用同一套导入导出（不是只给设备做）

## 联动看板（实验室页顶部）
把「单看一个表看不出来」的问题集中显示：
- 设备超期 → 能力矩阵里依赖它的项目标红「暂停接单」
- QC 超限 → 有没有对应的 NC 跟上来
- 内审不符合 → 有没有转成 NC
- 环境超限 → 有没有开 NC
- 留样 90 天内到期 / 委托单待复核 / 高风险 CAPA 未闭环

## 踩过的坑
- **grid 的 `1fr` 最小尺寸是 auto** —— input 的 size 默认宽度会把列撑破
  → 改 flex 布局 + `min-width:0`
- **`.tabs button` 与 `.tab` 是两套选择器** —— 只改一套导致「全部 16」被压扁
- **全局 `input{width:100%}` 污染卡片内 input** —— 卡片里要自己控宽
- **数据源不统一导致联动失效** —— 能力矩阵读种子数据，看不到 ledger 里改过的设备
  → `data()` 统一优先读 `Ledger.rows()`
