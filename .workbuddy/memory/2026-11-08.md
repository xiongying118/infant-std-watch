## 关键教训（写下来别再踩）
- **详情页 200 不等于条目还在**：ttbz 详情页是 SPA 壳，伪造 ID 也返回 200 + 同样 241471 字节。
  必须用 `getPortalStandardById` JSON 接口，它对不存在的 ID 返回「未找到对应的标准信息」
- **该接口需先 POST 列表接口建会话**，否则回「访问受限」HTML（也是 200，极易误判）
- **检索接口只返回「现行」**：团标废止后直接从搜索结果消失，所以「少一条」≠「漏采」
- **总局子栏目 tagId 是「内容区域」**，主栏目是「当前内容」；HTML 结构也不同（ul/li vs tr）
- **总局列表无分页参数**（pageNo/pageIndex/currentPage 全返回同样 26 行）
- node 实际路径 `22.22.2-6`（crawler.py 里写死的 `22.22.2-3` 已失效）
